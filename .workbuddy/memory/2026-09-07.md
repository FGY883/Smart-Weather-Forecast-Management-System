## 修复：前端页面中文乱码

### 现象
首页预警标题、天气状况等数据库来源的文字显示为「鍖椾含甯傞珮娓╅粍鑹查\ufffd璀\ufffd」类乱码。

### 排查结论（根因）
`spring.sql.init.encoding` 未配置 → 默认 `null` → 回落到 JVM 平台默认编码，
Windows 中文环境为 GBK。UTF-8 编码的 `schema.sql` / `data.sql` 被按 GBK 解码，
中文以乱码形式**写入数据库**，页面读取后自然乱码。

注意：不是编译期问题（class 常量正常），也不是模板/响应编码问题
（模板有 `<meta charset="UTF-8">`，响应头 `text/html;charset=UTF-8`，Thymeleaf 已配 UTF-8）。

### A/B 对照实验验证
用临时库分别启动应用：
- 不指定编码 → 预警表 4 个乱码字段
- 指定 `--spring.sql.init.encoding=UTF-8` → 0 乱码

### 改动
1. `application.yml`
   - 新增 `spring.sql.init.encoding: UTF-8`（关键修复）
   - **踩坑**：曾把 JDBC `characterEncoding=utf8` 改成 `utf8mb4`，
     导致 JDK8 + Connector/J 8.0.33 启动失败
     （`UnsupportedEncodingException: utf8mb4`）。已回退为 `utf8`。
2. `src/main/resources/sql/data.sql`
   - 改为 `INSERT ... SELECT ... WHERE NOT EXISTS` 幂等写法。
   - 原因：`spring.sql.init.mode=always` 每次启动都执行，而
     weather_warning / weather_data / ai_prediction / push_record / user_warning_notice
     没有唯一约束，`INSERT IGNORE` 无法去重，预警已累积到 16 条。
   - weather_favorite、weather_statistics 已有唯一键，仍用 `INSERT IGNORE`。
3. 数据库修复：备份到 `db_backup_before_utf8fix.sql`，删除全部乱码行
   （weather_warning 16、weather_data 28、ai_prediction 28、weather_favorite 3、
   weather_statistics 12、push_record 12、user_warning_notice 8），再以 UTF-8 重灌。

## 修复：AI 智能预测功能失效 + 温度误差大

### 三个根因
1. `WeatherApiUtil.getHistoricalWeather`：解析 `weather` 字段，但和风历史接口实际返回 `weatherDaily` → 30 天历史永远取不到；日期还用了 `yyyy-MM-dd`（接口要求 `yyyyMMdd`）。
2. `AiPredictionServiceImpl`：直接用 `selectByCityAndDateRange` 原始行回归——实时行 tempMax/tempMin 为 NULL 被映射成 0，同一天约 7 条重复预报行 → 回归输入即垃圾（北京实测预测 36-37°C，实际 27-29°C，误差 ~9°C）。
3. `predictValues`：线性外推无约束漂移；季节项用数组下标当"年中第几天"（恒≈0，写法错误）；无范围保护。

### 修复
- `WeatherApiUtil.getHistoricalWeather`：解析 `weatherDaily`（兼容 weather），日期用 BASIC_ISO_DATE；天气文本/风向/风速取自 `weatherHourly` 中最接近 12:00 的一条；逐日 try/catch。
- `AiPredictionServiceImpl.generatePrediction`：新增 `aggregateByDay`——按天聚合（最高温取 tempMax/temp 较大、最低温取较小、湿度平均、降水最大、文本优先 data_type>=2 的行），去重并消除 NULL→0；库内不足 30 天时调用历史接口补齐（免费版只能取最近 10 天）；预测后保证 min<=max；置信度改用 tempMax 序列。
- `AiPredictionUtil.predictValues`：斜率限幅 ±0.5/天；回归外推对均值偏离按 0.88^i 阻尼回拉（均值回复）；与 7 天加权移动平均 6:4 融合；输出限制在观测区间 ±4；删除错误季节项。
- `predictTempMax/TempMin`：NULL 回退到 temp 并过滤无温度行。

### 实测（8081 实例）
| 城市 | 预测 max/min | 近一周真实 | 结论 |
|---|---|---|---|
| 北京 | 31.1/19.7 | 29-31/19-20 | 贴合 |
| 厦门（新城市，自动补齐10天历史）| 27.6/23.8 | 25-30/24-26 | 贴合 |
| 武汉（库内129行脏数据）| 28.5/21.3 | 26-30/20-22 | 贴合 |
- `/weather/ai-forecast/101010100` 页面渲染 7 行预测，无错误提示。

注意：和风免费版历史接口仅支持最近 10 天，`ai.prediction.history-days=30` 目标在数据充足后逐步累积达成。
