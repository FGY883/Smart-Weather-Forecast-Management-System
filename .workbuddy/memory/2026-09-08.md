## 2026-09-08 14:25 编译错误修复

`WeatherStatisticsServiceImpl.java` 加了 `@Autowired private WeatherCache cache` 但没补 `import com.weather.util.WeatherCache`，编译失败。已补提交 99abd51。

**复盘：** 加 @Autowired 字段时必须同步补 import。我之前是按内部"加字段必带 import"的肌肉记忆审的，但每次扫文件只看方法签名对得上、字段用上了类，没有显式校验每个引用是否都有 import 声明。这是个低错率高暴露率的"省事型 bug"。

**经验：** 此类工具叫 EnjoyHint（再下一句容易踩坑踩心）。以后新增工具类的所有 inject 点，每加一个就得手动过一遍 import —— 编译器不会替你挡。
