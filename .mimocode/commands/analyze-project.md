# Analyze Project Command

## Description
Quickly analyze project structure and generate a summary report.

## Usage
```
/analyze-project [project_path]
```

## Parameters
- `project_path`: Optional path to project directory (default: current directory)

## Workflow
1. Explore project directory structure
2. Identify technology stack
3. Analyze key configuration files
4. Generate summary report

## Output
- Project type and framework
- Technology stack table
- Directory structure overview
- Key components description
- Database schema (if applicable)
- API endpoints (if applicable)

## Example
```
/analyze-project C:\Users\Justi\Desktop\Qwen Code Project\基于Spring Boot+Thymeleaf+AI的智能天气预报系统的设计与实现
```

## Notes
- This command provides quick project analysis
- Can be used as starting point for documentation
- Supports both Chinese and English projects
