# Explore Project Command

## Description
Thoroughly explore and analyze project structure.

## Usage
```
/explore-project [project_path]
```

## Parameters
- `project_path`: Optional path to project directory (default: current directory)

## Workflow
1. Scan directory structure
2. Identify key files and configurations
3. Analyze technology stack
4. Map architecture and components
5. Generate exploration report

## Example
```
/explore-project .
```

## Output
- Project overview
- Technology stack table
- Directory structure
- Key components description
- Database schema
- API endpoints
- Configuration files

## Notes
- This command provides comprehensive project analysis
- Can be used as starting point for other tasks
- Supports both Chinese and English projects
