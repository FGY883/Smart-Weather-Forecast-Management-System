# Project Structure Exploration

## Description
Thoroughly explore and analyze project structure, technology stack, and architecture. This skill handles the repeated workflow of understanding project components.

## Workflow

### 1. Directory Structure Analysis
- Use `Glob` to find all files and directories
- Identify project type (Spring Boot, Vue, React, etc.)
- Map directory structure and key files

### 2. Technology Stack Identification
- Read package.json, pom.xml, requirements.txt
- Identify frameworks, libraries, and versions
- Check for Docker, CI/CD configurations

### 3. Architecture Analysis
- Identify architectural patterns (MVC, microservices, monolithic)
- Map component relationships
- Understand data flow and dependencies

### 4. Key Files Analysis
- Configuration files (application.yml, .env, docker-compose.yml)
- Entry points (main classes, index files)
- Database schemas and models
- API endpoints and routes

### 5. Documentation Generation
Generate structured report with:
- Project overview
- Technology stack table
- Architecture diagram
- Directory structure
- Key components description
- Database schema
- API endpoints

## Example Usage
```
User: 请先全面了解这个项目
Agent: [Explores project] → [Generates comprehensive analysis report]
```
